# 纳音 · 六十甲子五行

**纳音**是把**六十甲子**每两柱（一阳干支 + 一阴干支）合成一「音」，共三十音，各配一枚**五行意象**（海中金、炉中火、大林木……）。它以「天干定五音、地支定十二律、合律取五行」为骨，是干支体系上叠加的第二层五行标签，用于命理、择日、堪舆的生克判断。

## 来源与算法

| 要素 | 内容 |
|------|------|
| 天干定五音 | 甲己→土（宫）、乙庚→金（商）、丙辛→水（羽）、丁壬→木（角）、戊癸→火（徵）。阳干「太」、阴干「少」 |
| 地支定十二律 | 子=黄钟、丑=大吕、寅=太簇、卯=夹钟、辰=姑洗、巳=仲吕、午=蕤宾、未=林钟、申=夷则、酉=南吕、戌=无射、亥=应钟 |
| 大衍算式 | 干数（甲己=9、乙庚=8、丙辛=7、丁壬=6、戊癸=5）+ 支数（子午=9、丑未=8、寅申=7、卯酉=6、辰戌=5、巳亥=4），49 −（干+支），除 5 取余：**1 金、2 土、3 水、4 木、0 火** |
| 命名依据 | 算出五行后，按地支方位、四季旺衰、十二长生状态赋予意象（沉、藏、显、旺各得其名） |

## 气数等级（按五行归类）
